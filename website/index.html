03 / GOOD TO KNOW

还有些事，
你可能想知道。

查看使用文档 →
已经有 DSH，为什么还需要 Sayrun？+

如果你用着 DSH，也习惯在 zsh 里自己敲命令，Sayrun 可以把两种操作接在一起。临时需要 AI 帮忙时，在原来的提示符直接提问；处理完回到提示符，继续工作。Sayrun 复用已认证的 DSH，无需为每次求助先进入独立的 AI 对话界面。

Sayrun 会自动执行命令吗？+

默认一律询问，每条新命令都需要你明确批准。也可在 setup 选择普通授权（非 sudo 命令自动执行）或完全授权（先验证 sudo，之后自动执行；需要提权仍显式写 sudo），或用 sayrun config set approval.mode ask|normal|full 修改。界面会先显示完整命令、执行目录和可选操作；你也可以编辑或拒绝。Sayrun 的审批机制不等同于操作系统沙箱。

需要另外配置模型吗？+

当前内置 DSH 后端。请先安装 DSH、完成认证并确保它位于 PATH 中。Sayrun 复用已有凭证；安装 Sayrun 本身不会安装或登录 DSH。

原来的 shell 命令还能照常用吗？+

可以。普通命令、别名、函数和多行语法继续交给 zsh。自然语言会进入 Sayrun，无法明确识别的输入会尝试分类或询问你。随时运行 sayrun shell off 关闭集成。

继续任务时会重放旧命令吗？+

不会。继续任务时会恢复对话上下文；只有你提交新请求，才会按当前配置的授权模式执行下一步。
