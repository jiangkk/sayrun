03 / GOOD TO KNOW

还有些事，
你可能想知道。

查看使用文档 →
Sayrun 会自动执行命令吗？+

每条新命令都需要你明确批准。界面会先显示完整命令、执行目录和可选操作；你也可以编辑或拒绝。Sayrun 的审批机制不等同于操作系统沙箱。

需要另外配置模型吗？+

当前内置 DSH 后端。请先安装 DSH、完成认证并确保它位于 PATH 中。Sayrun 复用已有凭证；安装 Sayrun 本身不会安装或登录 DSH。

原来的 shell 命令还能照常用吗？+

可以。普通命令、别名、函数和多行语法继续交给 zsh。自然语言会进入 Sayrun，无法明确识别的输入会尝试分类或询问你。随时运行 sayrun shell off 关闭集成。

继续任务时会重放旧命令吗？+

不会。当前 DSH 适配器会根据可见历史创建新的上下文分支。只有你提交了新请求，并明确批准新命令后，才会执行下一步。
