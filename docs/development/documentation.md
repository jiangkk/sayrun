# 文档维护规范

[文档索引](../README.md) · 分类：开发维护 · 状态：当前

本文适用于仓库 Markdown 文档及官网中的使用说明。新增内容先确定读者与用途，再选择目录；修改功能时同步更新对应的主文档和对外摘要。

## 内容放在哪里

| 内容 | 维护位置 |
| --- | --- |
| 产品介绍、安装捷径和快速开始 | 根目录 `README.md`；完整操作链接到使用手册 |
| 用户命令、配置、恢复与故障处理 | `docs/guide/` |
| 适配器接口、传输、字段与约束 | `docs/reference/` |
| 架构、开发环境、测试、发布和维护流程 | `docs/development/` |
| 历史设计、已被替代的方案与迁移背景 | `docs/archive/` |
| 贡献、安全报告和版本变更 | 根目录 `CONTRIBUTING.md`、`SECURITY.md`、`CHANGELOG.md` |
| 官网本地预览与目录说明 | `website/README.md`；部署流程链接到发布文档 |

不为没有内容的类别创建空目录。现阶段不把一份连贯的手册拆成大量短页面；当主题有独立读者、入口或维护频率时再拆分。

## 文件与页面结构

- 文件名使用小写英文和连字符，如 `backend-protocol.md`；目录入口统一使用 `README.md`。根目录常用社区文件保留现有大写命名。
- `docs/` 中的内容页面以一个一级标题开头，随后放文档索引链接、分类和状态，再用一段话说明读者、用途及相关文档。`docs/README.md` 是导航入口，不套用内容页格式。
- 标题按层级递进，不跳级。正文默认使用中文，保留代码、标识符和必要的技术术语。
- 标题、列表、表格与代码块之间留空行；代码块注明语言，例如 `sh`、`zsh`、`toml`、`json`、`text`。
- 命令示例说明执行目录、前置条件、是否连接真实模型或写入用户配置；占位符前后一致。版本示例说明需替换为目标版本。

内容页的最小结构如下，按所在目录调整索引的相对路径：

```markdown
# 主题名称

[文档索引](../README.md) · 分类：开发维护 · 状态：当前

本文面向……，说明……。相关主题见……。

## 第一个主题
```

## 当前说明、提案与归档

当前指南与参考只描述已实现行为。实验能力明确写出限制；未来方案标为提案，不写成使用承诺。文档与实现、测试冲突时，先核实预期行为，再同步修正文档或实现。

需要独立评审的方案放在相关主题目录，页面标明“状态：提案”，写明日期、问题、范围、方案、待决事项和验收方式。方案实施后将有效结论写入当前指南、参考或架构文档，原方案转入 `archive/`。

归档页标明初稿与归档日期，并链接当前说明。归档正文保留当时语境，不再追踪最新功能；仅修复链接、明显笔误或补充当前文档入口。更新历史事实时说明修订原因。

## 减少重复与同步遗漏

每个主题有一个维护完整细节的主文档，其他页面保留必要摘要并链接过去：

| 主题 | 主文档 | 常见同步位置 |
| --- | --- | --- |
| 用户行为、命令和配置 | [使用手册](../guide/usage.md) | 根 README、CLI 帮助、`website/docs.html` 与首页 |
| 后端能力与进程协议 | [后端协议参考](../reference/backend-protocol.md) | 共享类型、实现、协议测试 |
| 模块职责与依赖 | [架构文档](architecture.md) | 目录概览、实际入口与源码 |
| 开发环境与验证命令 | [构建与测试](testing.md) | `package.json`、测试入口、CI；贡献与发布文档保留必要快速清单 |
| 发包、公开导出与部署 | [发布文档](releasing.md) | 包白名单、发布钩子与工作流；官网说明只保留入口 |

官网当前为手工维护的静态 HTML，不会自动从 Markdown 生成。用户行为变化时同步核对官网；仅调整仓库文档分类不需要重新设计官网。

## 修改完成前

1. 新增、移动或归档文档后更新[文档索引](../README.md)。
2. 使用相对链接连接仓库文件，移动后检查文件路径与章节锚点；全文搜索旧路径，更新 Markdown、脚本和官网中的引用。
3. 核对命令与 `--help`、脚本或测试，平台与验证声明只写已取得的证据；结构调整本身不代表命令已重新验证。
4. 保留外部使用的资产路径，尤其是 npm 和 CDN 使用的 `docs/images/approval-preview.png`。
5. 检查最终差异，避免私人路径、凭证、真实会话和运行数据进入文档；确认归档提案没有被当作当前功能。

根目录 [AGENTS.md](../../AGENTS.md) 引用这里的文档入口和维护规则，只保留开发约束与导航，避免再维护一份完整目录树或重复的开发手册。
